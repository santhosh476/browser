# Google Chrome Clone (Chromium Engine)

A custom, fully-functional Google Chrome clone built using Electron and the Chromium browser engine.

## Features
- **Authentic Google Chrome UI**: Modern Chrome-styled tab bar, Omnibox, navigation toolbar, and bookmarks.
- **Full Multi-Tab Support**: Open multiple tabs, switch between tabs, close tabs with close button or middle-click.
- **Omnibox (Address & Search Bar)**:
  - Direct URL navigation (e.g. `google.com`, `github.com`).
  - Google search fallback for queries.
  - Page loading indicator and security/SSL status icon.
- **Browser Navigation Controls**: Back, Forward, Reload/Stop, and Home buttons.
- **Bookmarks Bar**: Quick access to Google, YouTube, GitHub, Wikipedia, etc.
- **Developer Tools**: Toggle Chromium DevTools using the icon in the toolbar or pressing `F12`.
- **Keyboard Shortcuts**:
  - `Ctrl + T`: New Tab
  - `Ctrl + W`: Close Active Tab
  - `Ctrl + R` / `F5`: Reload
  - `Ctrl + L`: Focus Address Bar
  - `F12`: Inspect / Developer Tools
  - `Ctrl + +` / `Ctrl + -`: Zoom in / out

## How to Run
Double-click `launch-chrome.bat` or run:
```bash
npm start
```
